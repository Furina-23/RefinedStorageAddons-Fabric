# Refined Storage Addons [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE.md)

This project is an unofficial Fabric port of Refined Storage Addons.

The original mod was created and maintained by [Raoul van den Berge](https://github.com/raoulvdberge) and the [Refined Mods](https://github.com/refinedmods) team. We sincerely thank them and all contributors for their work.

## About

This is an addon mod for Refined Storage.

This mod will have all features that belong in an addon mod and not in the core Refined Storage mod.

Currently, Refined Storage Addons only adds the "Wireless Crafting Grid", a wireless variant of the Crafting Grid (Refined Storage only contains a Wireless Grid, without crafting-abilities, natively.)

## Building

Clone the repository and import the Gradle project.
